🎮 Tic-Tac-Toe Arena
Welcome to Tic-Tac-Toe Arena! This is a fun, interactive web-based version of the classic Tic-Tac-Toe game, built using TypeScript and Vite.

✨ Features
🎯 Classic Tic-Tac-Toe gameplay
❌ X vs. O player experience
🏆 Win detection
🤝 Draw detection
🔄 Restart the game and play again
📱 Simple and responsive user interface
🛠️ Technologies Used
TypeScript
Vite
HTML5
CSS3
🚀 Getting Started
Follow these steps to run the project on your computer.

Prerequisites
Install Node.js before starting.

Installation
1. Clone the repository


git clone YOUR_REPOSITORY_URL
2. Open the project folder


cd YOUR_PROJECT_FOLDER
3. Install dependencies


npm install
4. Start the development server


npm run dev
5. Open the local URL shown in your terminal to play the game.

📦 Build for Production
Run the following command to build the project:


npm run build
To preview the production build:


npm run preview
🎮 How to Play
Two players take turns placing X and O on the board.
The first player to align three symbols horizontally, vertically, or diagonally wins.
If all nine cells are filled and nobody wins, the game ends in a draw.
Restart the game to play again!
